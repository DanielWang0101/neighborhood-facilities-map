# 周边设施标注系统

这是一个帮助用户标注地址周围必要设施（如大学、银行、餐厅、超市、购物中心、景点、公园等）的网站应用。

## 功能特性

- 地址搜索与自动完成
- 获取用户位置（需用户授权）
- 地图显示周边设施
- 可自定义设施类型和搜索范围（1-10公里）
- 生成并下载带有设施标注的地图图片

## 技术栈

- React 18
- TypeScript
- Zustand (状态管理)
- Tailwind CSS (样式)
- Leaflet (地图库)
- OpenStreetMap数据

## 开发指南

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 使用方法

1. 首次访问网站时会请求获取您的地理位置，如果允许，地图将显示您的当前位置
2. 您可以在左侧搜索栏中输入并搜索任何北美地区的地址
3. 在搜索栏下方的设置面板中，选择要显示的设施类型和搜索范围
4. 地图上会标注所选设施，右侧显示图例
5. 点击"下载图片"按钮可获取当前地图和图例的截图
